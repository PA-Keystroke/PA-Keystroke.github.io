PA Keystroke Wiki

从首次启动、添加控件，到预设管理和 OBS 捕获，这里按实际操作顺序整理了完整步骤。

快速开始 系统要求 输入模式 添加按键 序列式监听 添加鼠标 位移指示器 滚轮指示器 瀑布流 添加文本 手柄控件 编辑控件 对齐控件 快捷键 管理预设 覆盖层、个性化与动效 覆盖层设置 在 OBS 中使用 自动更新 数据目录 常见问题 反馈

01

快速开始

下载免安装版本后，按下面的顺序完成第一次使用即可。

  1. 1
    下载程序

    从官网或最新 Release 页面下载 PA-Keystroke.exe。

  2. 2
    运行程序

    双击运行，并按 Windows 提示允许管理员权限。程序会打开设置窗口和透明覆盖层。

  3. 3
    选择输入模式

    根据场景选择键盘、手柄或自动识别模式。

  4. 4
    调整布局与样式

    在预览区调整控件，并在 Dock 的“覆盖层”“个性化”“动效”“布局”“应用”“热键”卡片中调整覆盖层、外观、触发动画、界面布局和快捷键。

  5. 5
    保存并应用

    完成修改后必须点击“保存并应用”，覆盖层才会使用新布局。

  6. 6
    在 OBS 中添加窗口捕获

    选择 PA Keystroke Overlay，采集方式选择 Windows 10（1903 或更新版本）。

02

系统要求

  • Windows 10 64 位
  • Windows 11 64 位
  • 使用手柄时，需要 Windows 能正常识别 Xbox 兼容手柄

PA Keystroke 是免安装程序，不需要安装到固定目录。

03

选择输入模式

键盘输入

始终显示键盘布局。

手柄输入

始终显示手柄布局。

自动识别

根据最近操作的设备，自动切换键盘或手柄布局。

鼠标操作不会触发自动识别模式切换，只有键盘按键和手柄操作会参与判断。

自动识别模式下，预览区和预设栏会锁定为只读，避免误改布局。

04

添加按键

  1. 1
    点击“＋ 添加”

    在菜单中选择“按键”。

  2. 2
    填写按键名称

    名称用于在编辑列表和预览区识别该控件。

  3. 3
    绑定键盘按键

    点击“绑定按键”，然后按下需要显示的键盘按键。

  4. 4
    调整位置和尺寸

    在上方预览区拖动控件；编辑完成后点击“保存”。

  5. 5
    保存并应用

    回到主窗口点击“保存并应用”，覆盖层才会更新。

按键按下时，控件会按“动效”卡片中选择的效果反馈。

05

添加序列式监听

  1. 1
    选择“序列式监听”

    点击“＋ 添加”，然后选择“序列式监听”。

  2. 2
    设置排列与尺寸

    选择横向、横向反转、纵向或纵向反转，并设置键帽大小和键间距。

  3. 3
    选择监听范围

    可选择全部按键、仅快捷键（修饰键组合）或自定义筛选。

  4. 4
    设置停留与历史

    “停留时长”控制组合结束后保留多久；开启“保留历史记录”后，历史组合会占用控件长度，放不下时优先淘汰最旧的组合。

  5. 5
    保存并应用

    选择“自定义筛选”时，在“自定义按键”中填写例如 ctrl_l, shift, alt_l, a。

序列式监听会按按键按下的顺序记录组合键，每组组合在控件中依次排列。

06

添加鼠标

  1. 1
    选择“鼠标”

    点击“＋ 添加”，然后选择“鼠标”。

  2. 2
    设置显示区域

    选择是否显示侧键、中键、滚轮指示和位移指示。

  3. 3
    调整预览控件

    移动鼠标控件并拖动边缘改变尺寸。

  4. 4
    保存并应用

    先点击弹窗中的“保存”，再点击主窗口的“保存并应用”。

鼠标控件支持左键、右键、中键、侧键 1 和侧键 2。

鼠标主体内部的位移点会跟随鼠标移动，停止后逐渐回到中心。滚轮指示和位移指示可以在编辑页分别开启或关闭。

07

添加位移指示器

  1. 1
    添加控件

    选择“位移指示器”。

  2. 2
    调整参数

    设置圆点尺寸、鼠标敏感度和回中速度。

  3. 3
    调整位置和尺寸

    在预览区拖动控件或拖动边缘调整显示范围。

  4. 4
    保存并应用

    完成修改后应用布局。

位移指示器会显示鼠标移动方向，并在停止移动后逐渐回到中心。

这是独立的位移指示器控件；如果只需要在鼠标主体内部显示位移点，直接在鼠标控件的编辑页开启“显示位移指示”即可。

08

添加滚轮指示器

  1. 1
    添加控件

    在键盘布局中点击“＋ 添加”，然后选择“滚轮指示器”。

  2. 2
    调整参数

    设置滑条宽度、滚动敏感度和回中速度。

  3. 3
    调整位置和尺寸

    滚轮指示器默认是竖向长条，可在预览区拖动控件或拖动边缘调整范围。

  4. 4
    保存并应用

    先点击弹窗中的“保存”，再点击主窗口的“保存并应用”。

鼠标滚轮向上时滑条向上偏移，向下时向下偏移。连续滚动越快，偏移越大；停止滚动后，滑条会逐渐回到中间。

09

添加瀑布流

  1. 1
    选择“瀑布流”

    点击“＋ 添加”，然后选择“瀑布流”。

  2. 2
    设置输出方向

    可选向上、向下、向左或向右；切换方向时控件宽高会自动对调。

  3. 3
    设置流动速度

    速度范围 20–1200 px/s。

  4. 4
    调整位置和尺寸

    输出方向的长度决定方块能显示的范围；读取侧的长度决定能容纳多少个按键。

  5. 5
    保存并应用

    覆盖层会使用新的瀑布流设置。

瀑布流不是普通按键，而是一个附加渲染控件：

  • 它只会读取整段宽度都处于读取侧范围内、并且贴住读取侧的普通键盘按键。
  • 读取侧与输出方向相反；例如向上输出时，读取侧在下方。
  • 按住按键时，会持续输出对应宽度的圆角方块；松手后方块继续流动并渐隐。
  • 每条通道的宽度等于对应按键宽度。
  • 预览区会显示输出方向、读取侧和每个已接入按键的轨道，接入和取消接入时有生长/缩回动画。轨道只在编辑预览显示，覆盖层中不显示。

10

添加文本

  1. 1
    选择“文本”

    输入需要显示的文字内容。

  2. 2
    设置基础文字

    调整字体大小、行距、字间距和文字颜色。

  3. 3
    设置对齐和字形

    选择水平、垂直对齐，以及粗体和斜体。

  4. 4
    设置视觉效果

    按需要开启描边、阴影和背景，并分别调整颜色与透明度。

  5. 5
    保存并应用

    文本支持多行和自动换行。

11

添加手柄控件

添加整只手柄

  1. 1
    切换到手柄输入模式

    在输入模式选择器中选择“手柄输入”。

  2. 2
    添加整只手柄

    点击“＋ 添加”，然后选择“整只手柄”。

  3. 3
    调整位置和尺寸

    在预览区完成布局调整，再点击“保存并应用”。

整只手柄会显示 A、B、X、Y、LB、RB、LT、RT、十字方向键、View、Xbox、Menu 和左右摇杆。

添加独立手柄控件

在手柄模式的“＋ 添加”菜单中，可以分别选择“手柄按键”“摇杆”“扳机”和“文本”。添加后可以单独调整位置、尺寸和显示名称。

手柄布局与显示名称

手柄模式（以及自动识别模式）下，模式切换和预设选择器旁边会出现“手柄布局”选择器，可切换 Xbox、PS、Switch 三种排布。

  • 跟随布局：面键符号、肩键和扳机文字会随布局变化。例如 PS 布局显示 △ □ ○ × 与 L1 / R1 / L2 / R2，Switch 布局显示 A / B / X / Y 与 L / R / ZL / ZR。
  • 自定义名称：会显示文字的手柄控件（面键、LB/RB、LT/RT、十字键、L3/R3）可以自定义显示名称；一旦改过名字，就以自定义文字为准，不再随布局自动变化。
  • 恢复自动：重新编辑该控件，把名称改回它当前的默认文字再保存，就会重新跟随布局。
  • 不能改名：只画图标的 View、Xbox、Menu 和左右摇杆，编辑窗口里不会显示名称输入框。

13

对齐多个控件

多选两个以上控件后，可以把它们按同一个参照物摆齐。

  1. 1
    选中控件

    按住 Shift 框选，或开启多选模式后逐个点选，至少选中两个控件。

  2. 2
    进入对齐

    点击工具栏上的“对齐”按钮，或按 Ctrl+Shift+A。

  3. 3
    选择参照物

    按提示“请选择参照物...”，在预览中点击一个参照控件。

  4. 4
    选择对齐方式

    水平中线对齐、垂直中线对齐、左对齐、右对齐、顶对齐、底对齐或尺寸对齐。

对齐对普通按键、鼠标、指示器、文本、序列式监听、瀑布流和手柄控件都有效，操作同样会记入撤回历史，可以用 Ctrl+Z 撤销。

15

管理预设

预设用于保存多套布局。键盘预设和手柄预设互相独立，切换设备模式时不会互相覆盖。

  1. 1
    切换预设

    在预览窗下方打开预设选择器，选择已有预设即可切换。

  2. 2
    创建预设

    点击“＋ 添加预设”，新建后可直接输入名称。

  3. 3
    重命名或删除

    自定义预设支持重命名和删除。只有未被选中的自定义预设可以被删除。

导出预设

  1. 在预设选择器中点击“导出预设”。
  2. 勾选需要导出的键盘预设和手柄预设，可以同时选择多套。
  3. 点击“导出”，选择保存位置。文件格式为 .json。
  4. 导出文件会写入当前软件版本，作为该预设支持的最低兼容版本。

导入预设

  1. 在预设选择器中点击“导入预设”。
  2. 选择一个或多个 .json 预设文件。
  3. 如果预设要求的最低兼容版本高于当前软件版本，会弹出兼容提示，可选择取消或仍然导入。
  4. 如果名称冲突，可分别为每项选择“覆盖”“跳过”或“副本”。
  5. 点击“继续导入”完成处理。

键盘配列预设

预设市场提供可直接导入的键盘配列预设。

使用全键盘映射预设时，不建议把“整体缩放”调整得过低。

16

覆盖层、个性化与动效

“覆盖层”卡片只保留覆盖层本身的控制项：

  • 覆盖层交互：锁定时鼠标点击穿透，解锁后可以拖动覆盖层。
  • 覆盖层显示：隐藏覆盖层，但仍可通过 OBS 窗口捕获。
  • 整体缩放：按比例调整覆盖层中所有控件的大小。

“个性化”卡片用于统一设置普通按键、鼠标、指示器和手柄控件的外观，以及软件界面样式：

  • 外观色：深色、浅色或自动跟随系统。
  • 主题色：用于界面强调、选中和开关状态，并自动校正对比度。
  • 不透明度：调整覆盖层整体透明程度。
  • 背景颜色：控制控件背景显示，可通过左侧勾选框开启或关闭。
  • 外框颜色：控制控件外框显示，可通过左侧勾选框开启或关闭。
  • 文字显示比例：整体放大或缩小键帽文字。
  • 文字阴影：控制键帽文字是否显示投影。
  • 阴影浓度：调整文字阴影的明显程度。

颜色支持 Alpha，可直接输入 #RRGGBBAA，也可以打开选色器后通过透明度滑条调整。

键帽文字颜色、触发颜色和阴影颜色会根据当前背景色自动推导，设置中不再单独提供手选。外框颜色关闭时，普通按键不显示外框；鼠标、指示器和手柄控件会恢复各自默认外框，避免控件不可见。

外观色和主题色只影响设置界面和预览区外观，不会改变覆盖层中按键、鼠标和手柄控件的实际样式。

动效卡片

“动效”卡片用于设置键帽触发时的按下动画，并提供独立预览键帽：

  • 键内效果：单选，包含简化（变色）、内缩、脉冲、回弹和果冻。
  • 键外效果：单选，包含无、光晕、涟漪和火花。
  • 键内效果和键外效果可以各选一个并同时生效。
  • 预览键帽会自动循环播放，也可以点击预览立即触发。
  • 动效作用于键盘按键、鼠标按键、手柄按键等会触发状态的键帽控件。
  • 动效设置保存在用户设置中，修改后立即同步到覆盖层。
  • 默认是“简化（变色）+ 无键外效果”，与旧版本行为一致。

布局卡片

“布局”卡片用于调整界面上几个固定元素的停靠位置，改完立即生效并自动保存：

  • 模式与预设位置：模式切换与预设切换的停靠位置，可选左上或左下。
  • Dock 栏位置：Dock 栏的停靠位置，可选底部、左侧或右侧。

Dock 栏一共有六个入口：覆盖层、个性化、动效、布局、应用和热键。切换位置时会有平滑过渡动画，不会影响控件布局和覆盖层。

窗口行为

设置窗口采用接近 Windows 原生应用的行为：

  • 拖动标题栏移动窗口，拖到屏幕边缘会吸附到对应位置。
  • 双击标题栏可以最大化或还原窗口。
  • 拖动窗口边缘或四角可以调整大小。
  • 右键标题栏可以打开 Windows 系统菜单。
  • 最小化、还原、最大化和贴边吸附都带有过渡动画。

覆盖层设置

整体不透明度

不透明度设置位于“个性化”卡片中，会统一改变所有控件和背景的整体透明程度。

整体缩放

“整体缩放”会改变覆盖层中控件的整体大小，适合适配不同分辨率的直播画面。

覆盖层交互

锁定后
  • 鼠标点击会穿透覆盖层
  • 不会拦截游戏或软件操作
  • 按键、文字和填充不会抢占鼠标
解锁后
  • 可以拖动调整覆盖层位置
  • 位置会自动保存
  • 重新启动后恢复到原位置

隐藏覆盖层

开启后覆盖层会移出所有屏幕，用户当前屏幕和直播画面中不会看到它，但窗口仍保持运行，可通过 OBS 的窗口捕获继续获取画面。

关闭隐藏后，覆盖层会恢复到隐藏前的位置。切换锁定、调整缩放或保存设置不会把隐藏中的覆盖层拉回屏幕。

应用设置

“应用”卡片可以控制开机自启动、启动时是否显示设置窗口、启动时检查更新，以及关闭设置窗口时是否退出程序。

系统托盘

系统托盘菜单提供设置、锁定覆盖层、隐藏覆盖层、开机自启动、关于和退出。

“隐藏覆盖层”与设置窗口中的同名开关双向同步，修改后会立即保存。

开机自启动

勾选托盘菜单或“应用”卡片中的“开机自启动”后，程序会在 Windows 登录时启动。

开机启动时是否显示设置窗口，由“应用”卡片中的“启动时显示设置”决定。关闭后只运行覆盖层并保留系统托盘图标；需要调整设置时，可以从托盘菜单点击“设置”或双击图标。

在 OBS 中使用

  1. 1
    添加来源

    在 OBS 的来源面板点击“＋”，选择“窗口捕获”。

  2. 2
    选择覆盖层窗口

    在窗口列表中选择 PA Keystroke Overlay。

  3. 3
    选择采集方式

    采集方式请选择 Windows 10（1903 或更新版本）。

  4. 4
    调整显示范围

    使用裁剪或滤镜调整覆盖层在画面中的位置和尺寸。

不要选择 PA Keystroke 设置主窗口，应选择独立的 PA Keystroke Overlay。

如果启用了“隐藏覆盖层”，窗口不会出现在用户屏幕上，但仍可通过窗口捕获获取画面。请确保使用“窗口捕获”，不要使用“显示器采集”。

自动检查更新

程序默认在启动时检查公开 Release 仓库，可以在“应用”卡片中关闭“启动时检查更新”。检查期间标题栏会显示加载动画；如果没有新版本，动画会自动隐藏。

发现新版本时，可以从更新提示中查看更新日志、打开发布页面、下载更新，并自动替换和重启。更新日志支持保留原文换行和显示 GitHub Release 正文中的远程图片。

也可以在关于页手动检查更新；关闭自动检查后，仍可通过关于页检查。

常见问题

Windows 显示“发布者未知”

当前版本未使用受信任的代码签名证书。请确认文件来自公开 Release 仓库，并核对 Release 页面提供的 SHA256。

覆盖层挡住鼠标操作

在设置页开启“锁定覆盖层”。锁定后点击会穿透覆盖层。

OBS 看不到覆盖层

确认使用“窗口捕获”，选择 PA Keystroke Overlay，并把采集方式设为 Windows 10（1903 或更新版本）。

手柄没有反应

确认手柄已被 Windows 识别，已选择手柄模式或开启自动识别，并已添加整只手柄或对应手柄控件。

没有检测到更新

确认电脑可以正常访问 GitHub，当前版本不是最新版本，并且 Release 中包含可下载的更新文件。
